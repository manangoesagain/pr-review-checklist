02How it works

Less “LGTM.”
More “why?”

Most review tools tell you if something is green. This one helps you notice what green forgot to explain.

  1. 01

    Paste a link

    Any public GitHub pull request, or a diff from git diff.

  2. 02

    Get the checklist

    Security, tests, breaking changes, docs and performance, each pointing at the exact line. A second check hides anything the code doesn't back up.

  3. 03

    Copy it to the PR

    Tick items as you go, then paste the checklist or a ready-made comment.

03

Ship the thing.
Keep the context.

Nothing is saved. When the AI reviewer is on, the changed code is sent to NVIDIA's AI service to be reviewed, so don't paste code you aren't allowed to share.
